## Task

### 🇵🇱 Treść zadania (PL)

Zadania należy zrealizować z wykorzystaniem schematu bazy danych Cycling.

Wyszukaj zespoły, których skład liczy co najmniej 5 zawodników. W rezultacie wyświetl `team_uci_code`, `team_name`.

**Podproblem:** Oblicz liczbę zawodników w każdym zespole wykorzystując tabelę `cycling.athlete`. Następnie przefiltruj tylko zespoły z liczbą zawodników >= 5.

### 🇬🇧 Task description (EN)

The tasks are to be done on the Cycling database schema.

Find the teams whose roster has at least 5 athletes. Show `team_uci_code`, `team_name`.

**Subproblem:** Count the athletes in each team using the `cycling.athlete` table. Then keep only the teams with 5 or more athletes.
