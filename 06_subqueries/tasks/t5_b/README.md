## Task

### 🇵🇱 Treść zadania (PL)

Utwórz zapytanie wybierające studentów kierunku Informatyka, którzy mają średnią ocen wyższą niż średnia ocen dowolnego ze studentów kierunku Matematyka. Wyniki uporządkuj rosnąco wg Nazwiska oraz Imienia.

### 🇬🇧 Task description (EN)

Create a query selecting the students of the Computer Science (Informatyka) field of study whose average grade is higher than the average grade of any of the students of the Mathematics (Matematyka) field of study. Sort the results in ascending order by last name and first name.
