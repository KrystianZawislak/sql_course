## Task

### 🇵🇱 Treść zadania (PL)

Utwórz zapytanie wyszukujące wszystkich nauczycieli akademickich, którzy w roku 2012 nie prowadzili żadnych zajęć fakultatywnych. Przedstawiając problem inaczej, wyszukaj nauczycieli akademickich do których w roku 2012 nie zapisał się na fakultet żaden student. Zapytanie powinno zwracać Tytuł, Imię, Nazwisko oraz Stanowisko. Dane osobowe nauczycieli akademickich znajdują się w tabeli prowadzacy w schemacie kadry.

### 🇬🇧 Task description (EN)

Create a query finding all academic teachers who did not run any elective classes in 2012. Put differently, find the academic teachers whose electives no student signed up for in 2012. The query should return the title, first name, last name and position. The teachers' personal data is in the prowadzacy (lecturers) table in the kadry schema.
