## Task

### 🇵🇱 Treść zadania (PL)

Utwórz zapytanie wyszukujące studenta/studentów, którzy otrzymali największą liczbę ocen niedostatecznych podczas studiów. Bierzemy pod uwagę wszystkie terminy (I, II oraz III).

### 🇬🇧 Task description (EN)

Create a query finding the student/students who got the largest number of failing grades during their studies. All attempts (I, II and III) are taken into account.
