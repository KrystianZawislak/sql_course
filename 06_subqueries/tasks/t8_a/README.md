## Task

### 🇵🇱 Treść zadania (PL)

Wykorzystując klazulę WITH utwórz zapytanie wybierające studentów, których średnia ocen jest wyższa od średniej ocen wszystkich studentów kierunku (np. średnia ocen studentów na kierunku Informatyka wynosi 3.84 a jedynym studentem który ma wyższą średnią równą 4.29 jest Arkadiusz Kania). Wyniki uporządkuj rosnąco wg Nazwiska oraz Imienia.

### 🇬🇧 Task description (EN)

Using the WITH clause, create a query selecting the students whose average grade is higher than the average grade of all students of their field of study (e.g. the average grade of Computer Science students is 3.84 and the only student with a higher average, 4.29, is Arkadiusz Kania). Sort the results in ascending order by last name and first name.
