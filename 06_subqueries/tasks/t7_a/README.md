## Task

### 🇵🇱 Treść zadania (PL)

Podzapytanie odwołujące się do wartości kolumny zapytania obejmującego (zewnętrznego) nazywa się podzapytaniem skorelowanym, ponieważ rezultaty podzapytania są skorelowane z każdym rekordem zapytania obejmującego (zewnętrznego).

Dokonaj analizy przykładowych zadań z tematów T1:T6 i zastanów się, które z przedstawionych podzapytań są podzapytaniami skorelowanymi.

### 🇬🇧 Task description (EN)

A subquery that refers to a column value of the enclosing (outer) query is called a correlated subquery, because the subquery's results are correlated with every record of the enclosing (outer) query.

Analyse the example tasks from topics T1–T6 and consider which of the subqueries shown are correlated subqueries.
