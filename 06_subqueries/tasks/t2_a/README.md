## Task

### 🇵🇱 Treść zadania (PL)

Utwórz zapytanie wyszukujące wszystkich studentów, którzy przynależą do WKU w województwie małopolskim tj. WKU w Tarnowie lub WKU w Nowym Sączu lub WKU w Krakowie. Jako wynik wykonania zapytania wyświetl Nr albumu, Imię oraz Nazwisko studenta.

### 🇬🇧 Task description (EN)

Create a query finding all students who belong to a WKU (military recruitment office) in the Lesser Poland (małopolskie) voivodeship, i.e. WKU w Tarnowie, WKU w Nowym Sączu or WKU w Krakowie. As the result, show the student's album number, first name and last name.
