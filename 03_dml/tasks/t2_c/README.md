## Task

### 🇵🇱 Treść zadania (PL)

Utwórz zapytanie tworzące tabelę **absolwenci**, której struktura jest identyczna jak struktura tabeli **studenci_kierunkow** a następnie uzupełnij utworzoną tabelę danymi studentów, którzy już ukończyli studia.

### 🇬🇧 Task description (EN)

Write a query that creates the **absolwenci** (graduates) table with a structure identical to the **studenci_kierunkow** (students' fields of study) table, and then fill the new table with the data of students who have already graduated.

## Files

| File           | Description |
| -------------- | ----------- |
| `solution.sql` | Creates `absolwenci` as an empty copy of `studenci_kierunkow` and fills it with graduates |
