## Task

### 🇵🇱 Treść zadania (PL)

Wykorzystując złączenia wewnętrzne/zewnętrzne naturalne określ kwerendę pozwalającą wyświetlić studentów którzy w semestrze I nie uzyskali żadnej oceny. Spośród wszystkich kolumn wybierz Nr albumu, Imię, Nazwisko oraz Kierunek studiów.

Skonfrontuj uzyskane zapytanie z analogicznymi kwerendami z zadań wcześniejszych. Jakie wnioski można przedstawić?

### 🇬🇧 Task description (EN)

Using natural inner/outer joins, define a query that displays the students who did not receive any grade in semester I. Of all columns, select Album number, First name, Last name and Course of study.

Compare the query with the analogous queries from the earlier tasks. What conclusions can be drawn?
