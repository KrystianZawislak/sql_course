## Task

### 🇵🇱 Treść zadania (PL)

W schemacie cycling utwórz zapytanie klasyfikujące zawodników do określonych kategorii na podstawie obliczonego BMI. W rozwiązaniu wykorzystaj dodatkową tymczasową tabelę bmi z kategoriami.

### 🇬🇧 Task description (EN)

In the `cycling` schema, create a query that classifies athletes into categories based on their calculated BMI. In the solution, use an additional temporary table `bmi` with the categories.
