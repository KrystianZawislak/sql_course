## Task

### 🇵🇱 Treść zadania (PL)

Określi liczbę rekordów w tabelach prowadzacy, przedmioty, oceny a następnie zdefiniuj zapytanie wykonujące złączenie krzyżowe w/w trzech tabel. Jaka jest liczba wynikowych rekordów? Jaką formułą można wyznaczyć liczbę wynikowych rekordów na podstawie liczby rekordów każdej z tabel uczestniczących w złączeniu?

### 🇬🇧 Task description (EN)

Determine the number of records in the tables `prowadzacy`, `przedmioty` and `oceny`, then define a query performing a cross join of these three tables. What is the number of resulting records? What formula gives the number of resulting records based on the number of records in each table taking part in the join?
