## Task

### 🇵🇱 Treść zadania (PL)

W schemacie cycling:

Wyszukaj informacje o zawodnikach którzy brali udział w jakichkolwiek zawodach. W przypadku, gdy zawodnik brał udział w wielu zawodach powinien w wyniku pojawić się wielokrotnie. W rezultacie należy uwzględnić informacje o zawodniku, zespole, zawodach oraz uzyskanym wyniku w postaci athlete_id, first_name, last_name, team_name, competition_name, rank. Przekształć zapytanie z w/w zadania do postaci wykorzystującej złączenia naturalne.

### 🇬🇧 Task description (EN)

In the `cycling` schema:

Find information about the athletes who took part in any competition. If an athlete took part in many competitions, they should appear in the result many times. The result should include information about the athlete, team, competition and the result achieved, as athlete_id, first_name, last_name, team_name, competition_name, rank. Rewrite the query to use natural joins.
