## Task

### 🇵🇱 Treść zadania (PL)

W schemacie cycling:

Utwórz klasyfikację zawodników wg następujących reguł: 1 miejsce = 100 pkt, 2 miejsce = 75 pkt, 3 miejsce = 50 pkt. W rezultacie należy uwzględnić informacje o zawodniku, zespole oraz łącznej liczbie punktów w postaci athlete_id, first_name, last_name, team_name, point. Przekształć zapytanie z w/w zadania tak, aby w klasyfikacja uwzlędniała także zawodników którzy w dotychczasowych zawodach nie uzyskali żadnych punktów.

### 🇬🇧 Task description (EN)

In the `cycling` schema:

Create a classification of athletes using the rules: 1st place = 100 pts, 2nd place = 75 pts, 3rd place = 50 pts. The result should include information about the athlete, team and total points, as athlete_id, first_name, last_name, team_name, point. Rewrite the query so that the classification also includes athletes who have not scored any points in the competitions so far.
