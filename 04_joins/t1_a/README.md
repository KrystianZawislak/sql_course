## Task

### 🇵🇱 Treść zadania (PL)

Wykorzystując przedstawioną składnię teta-złączeń, zdefiniuj zapytanie pozwalające wyświetlić wszystkie oceny studentów kierunku Matematyka uzyskane w semestrze I. Spośród wszystkich atrybutów wybierz Nr albumu, Imię, Nazwisko, Nazwę przedmiotu, Datę zaliczenia oraz Ocenę.

### 🇬🇧 Task description (EN)

Using the theta-join syntax shown, define a query that displays all grades of Mathematics students obtained in semester I. Of all attributes, select Album number, First name, Last name, Subject name, Pass date and Grade.
