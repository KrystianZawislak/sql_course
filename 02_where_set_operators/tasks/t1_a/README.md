## Task

### 🇵🇱 Treść zadania (PL)

Utwórz zapytanie, wybierające z tabeli **studenci** podstawowe informacje Nr albumu, Imię, Nazwisko, PESEL o wszystkich studentkach (płeć jest zapisana w 10 cyfrze PESEL-u). Następnie zmodyfikuj kwerendę tak, aby uzyskiwane wyniki były posortowane według Nazwiska studenta.

### 🇬🇧 Task description (EN)

Write a query that selects from the **studenci** (students) table the basic information — student ID number, first name, surname, PESEL — of all female students (the sex is encoded in the 10th digit of the PESEL). Then modify the query so that the results are sorted by the student's surname.
