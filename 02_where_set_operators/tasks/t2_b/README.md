## Task

### 🇵🇱 Treść zadania (PL)

Utwórz zapytanie wybierające z tabel **studenci** oraz **prowadzacy** wszystkich studentów oraz pracowników, których nazwisko rozpoczyna się od 'K'. Jako rezultat wyświetl Imię, Nazwisko osoby oraz Kategorię do jakiej osoba należy (STUDENT, PRACOWNIK).

### 🇬🇧 Task description (EN)

Write a query that selects from the **studenci** (students) and **prowadzacy** (lecturers) tables all students and employees whose surname starts with 'K'. As the result, show the First name, Surname and the Category the person belongs to (STUDENT, PRACOWNIK — employee).
