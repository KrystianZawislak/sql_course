## Task

### 🇵🇱 Treść zadania (PL)

Zdefiniuj zapytanie wyszukujące w tabeli **prowadzacy** wszystkich pracowników których Płaca zasadnicza zawiera się w przedziale domkniętym od 4000 zł do 6000 zł lub jest nieokreślona tj. ma wartość NULL. Spośród dostępnych atrybutów wyświetl Imię, Nazwisko, Tytuł, Stanowisko oraz Płacę zasadniczą. Płaca zasadnicza ma być zwrócona w postaci walutowej np. 4000 zł. Rezultat powinien być posortowany rosnąco wg Płacy zasadniczej z wartościami NULL na początku.

### 🇬🇧 Task description (EN)

Write a query that finds in the **prowadzacy** (lecturers) table all employees whose Base salary is in the closed range from 4000 zł to 6000 zł or is unknown, i.e. NULL. Of the available attributes, show the First name, Surname, Title, Position and Base salary. The base salary is to be returned as currency, e.g. 4000 zł. The result should be sorted ascending by Base salary, with NULL values first.
