## Task

### 🇵🇱 Treść zadania (PL)

Zdefiniuj kwerendę wyszukującą w tabeli **adresy** wszystkich studentów zamieszkujących w województwie podkarpackim lub lubuskim. Spośród dostępnych atrybutów wyświetl Ulicę, Numer domu, Kod pocztowy oraz Miasto.

### 🇬🇧 Task description (EN)

Write a query that finds in the **adresy** (addresses) table all students living in the Podkarpackie or Lubuskie voivodeship. Of the available attributes, show the Street, House number, Postal code and City.
