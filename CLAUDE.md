# Conventions

- One folder per exercise: `exN/` with `README.md` and the solution (`solution.sql`). Create it with `./new_exercise.sh "Title"`.
- README is written in English; the task is pasted verbatim in Polish and translated to English.
- README sections: Task (PL + EN), Files, How to run (with example output from a real run). No prose Solution/Notes sections — code review and explanations go in chat, in Polish.
- After adding an exercise, add a row to the table in the root `README.md`.
- One commit per exercise, e.g. `ex3: joins`, on `main`.
