## Task

### 🇵🇱 Treść zadania (PL)

Utwórz zapytanie obliczające średnią każdego studenta kierunku Informatyka, który otrzymał jakąkolwiek ocenę, a jako rezultat jej działania wyświetl Nr albumu oraz obliczoną Średnią tylko tych studentów, których średnia zawiera się w przedziale obustronnie domkniętym 3.50 - 4.00.

### 🇬🇧 Task description (EN)

Create a query calculating the average of every Computer Science (Informatyka) student who received any grade, and display the Album number and the calculated Average only for students whose average falls within the closed interval 3.50 - 4.00.
