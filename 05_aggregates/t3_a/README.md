## Task

### 🇵🇱 Treść zadania (PL)

Utwórz zapytanie obliczające średnią każdego studenta kierunku Informatyka, który otrzymał jakąkolwiek ocenę, a jako rezultat jej działania wyświetl Nr albumu oraz obliczoną Średnią tylko tych studentów, których średnia zawiera się w przedziale obustronnie domkniętym 3.50 - 4.00.

### 🇬🇧 Task description (EN)

Create a query calculating the average grade of every Informatyka (Computer Science) student who has received any grade, and display the Student number (Nr albumu) and the calculated Average (Średnia) only for the students whose average lies in the closed interval 3.50 – 4.00.
