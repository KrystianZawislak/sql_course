## Task

### 🇵🇱 Treść zadania (PL)

Oblicz w ramach pojedynczego zapytania:

- średnie BMI wszystkich kolarzy;
- łączną liczbę kolarzy;
- łączną liczbę kolarzy, dla których obliczono BMI.

### 🇬🇧 Task description (EN)

Calculate within a single query:

- the average BMI of all cyclists;
- the total number of cyclists;
- the total number of cyclists for whom BMI was calculated.
