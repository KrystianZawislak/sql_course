## Task

### 🇵🇱 Treść zadania (PL)

Nie wykorzystując klauzuli WHERE utwórz zapytanie obliczające liczbę studentów z orzeczonym stopniem niepełnosprawności na poszczególnych kierunkach studiów. W wyniku zapytania wyświetl Kierunek studiów oraz Liczbę studentów.

### 🇬🇧 Task description (EN)

Without using the WHERE clause, create a query calculating the number of students with a certified degree of disability in each field of study. Display the Field of study and the Number of students as the result.
