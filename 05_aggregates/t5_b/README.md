## Task

### 🇵🇱 Treść zadania (PL)

Zmodyfikuj utworzone w pkt a zapytanie tak, aby ranking był tworzony w obrębie poszczególnych kierunków studiów. Ranking poza Nr albumu, Imieniem, Nazwiskiem, Średnią ocen a także Pozycją w rankingu (1, 2, 3...) powinien zawierać także informację o Kierunku studiów.

### 🇬🇧 Task description (EN)

Modify the query created in point a so that the ranking is built within each field of study. Apart from the Album number, First name, Last name, Grade average and Position in the ranking (1, 2, 3...), the ranking should also contain the Field of study.
