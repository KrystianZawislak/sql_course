## Task

### 🇵🇱 Treść zadania (PL)

Zdefiniuj zapytanie wyszukujące wszystkich studentów, którzy przystępowali do zaliczenia dowolnego z przedmiotów więcej niż jednokrotnie (tzn. otrzymali więcej z dowolnego przedmiotu niż jedną ocenę). Jako wynik działania kwerendy wyświetl Nr albumu oraz Nazwę przedmiotu.

### 🇬🇧 Task description (EN)

Define a query finding all students who attempted to pass any subject more than once (i.e. received more than one grade in any subject). Display the Album number and Subject name as the result.
