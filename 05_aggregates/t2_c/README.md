## Task

### 🇵🇱 Treść zadania (PL)

Utwórz zapytanie obliczające średnią każdego studenta, który otrzymał jakąkolwiek ocenę, a jako rezultat jej działania wyświetl Nr albumu, Kierunek studiów oraz obliczoną Średnią. Średnia powinna być obliczana dla każdego studiowanego przez studenta kierunku oddzielnie.

### 🇬🇧 Task description (EN)

Create a query calculating the average grade of every student who has received any grade, and display the Student number (Nr albumu), the Field of study (Kierunek studiów) and the calculated Average (Średnia). The average should be calculated separately for each field of study the student is enrolled in.
