## Task

### 🇵🇱 Treść zadania (PL)

Utwórz zapytanie obliczające średnią każdego studenta, który otrzymał jakąkolwiek ocenę, a jako rezultat jej działania wyświetl Nr albumu, Kierunek studiów oraz obliczoną Średnią. Średnia powinna być obliczana dla każdego studiowanego przez studenta kierunku oddzielnie.

### 🇬🇧 Task description (EN)

Create a query calculating the average of every student who received any grade, and display the Album number, Field of study and the calculated Average. The average should be calculated separately for each field of study the student takes.
