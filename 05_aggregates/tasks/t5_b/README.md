## Task

### 🇵🇱 Treść zadania (PL)

Zmodyfikuj utworzone w pkt a zapytanie tak, aby ranking był tworzony w obrębie poszczególnych kierunków studiów. Ranking poza Nr albumu, Imieniem, Nazwiskiem, Średnią ocen a także Pozycją w rankingu (1, 2, 3...) powinien zawierać także informację o Kierunku studiów.

### 🇬🇧 Task description (EN)

Modify the query from point a (T5/A) so that the ranking is built within each field of study. Besides the Student number (Nr albumu), First name (Imię), Last name (Nazwisko), Average grade (Średnia ocen) and Position in the ranking (1, 2, 3...), the ranking should also include the Field of study (Kierunek studiów).
