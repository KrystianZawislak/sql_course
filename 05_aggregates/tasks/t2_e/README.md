## Task

### 🇵🇱 Treść zadania (PL)

Oblicz łączną liczbę punktów ECTS uzyskanych przez każdego studenta w semestrze 1. W rezultacie powinni zostać uwzględnieni także studenci, którzy podczas studiów nie uzyskali żadnych punktów tj. dla których liczba punktów ECTS wynosi 0. Rezultat powinien zawierać Nr albumu, Imię, Nazwisko, Nazwę kierunku studiów, Liczbę ECTS i powinien być sortowany liczbowo rosnąco wg Nr albumu.

### 🇬🇧 Task description (EN)

Calculate the total number of ECTS points earned by each student in semester 1. The result should also include students who earned no points during their studies, i.e. whose number of ECTS points is 0. The result should contain the Student number (Nr albumu), First name (Imię), Last name (Nazwisko), Field of study name (Nazwa kierunku studiów) and Number of ECTS points (Liczba ECTS), sorted numerically in ascending order by Student number.
