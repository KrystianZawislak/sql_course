## Task

### 🇵🇱 Treść zadania (PL)

Zdefiniuj zapytanie obliczające liczbę studentów przynależących do określonych Wojskowych Komend Uzupełnień. Jako wynik zapytania należy wyświetlić WKU oraz Liczbę studentów.

### 🇬🇧 Task description (EN)

Define a query calculating the number of students belonging to particular Military Recruitment Offices (Wojskowe Komendy Uzupełnień, WKU). The query should display the WKU and the Number of students (Liczba studentów).
