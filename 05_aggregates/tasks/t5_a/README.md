## Task

### 🇵🇱 Treść zadania (PL)

Utwórz zapytanie wyświetlające ranking średniej ocen studentów. Ranking powinien zawierać informacje o studencie tj. Nr albumu, Imię oraz Nazwisko, Średnią ocen a także Pozycję w rankingu (1, 2, 3...). Wykorzystaj w zadaniu funkcję `rank()`.

### 🇬🇧 Task description (EN)

Create a query displaying a ranking of the students' average grades. The ranking should contain information about the student, i.e. Student number (Nr albumu), First name (Imię) and Last name (Nazwisko), the Average grade (Średnia ocen) and the Position in the ranking (1, 2, 3...). Use the `rank()` function.
