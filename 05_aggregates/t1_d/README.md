## Task

### 🇵🇱 Treść zadania (PL)

Oblicz średnie BMI wszystkich kolarzy. Wynikiem powinna być wartość reprezentowana jako liczba rzeczywista o skali 2 np. BMI = 20.22. Formuła obliczająca indeks masy ciała BMI = weight/height² (kg/m²).

### 🇬🇧 Task description (EN)

Calculate the average BMI of all cyclists. The result should be a real number with a scale of 2, e.g. BMI = 20.22. The body mass index formula is BMI = weight/height² (kg/m²).
