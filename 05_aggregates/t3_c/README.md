## Task

### 🇵🇱 Treść zadania (PL)

Utwórz zapytanie wyszukujące fakultety, na które zapisało się w poszczególnych latach (2006, 2007...) co najmniej 5 studentów. Jako wynik zapytania wyświetl Nazwę fakultetu, Rok oraz Liczbę zapisanych studentów.

### 🇬🇧 Task description (EN)

Create a query finding the electives that at least 5 students enrolled in, per year (2006, 2007...). Display the Elective name, Year and Number of enrolled students as the result.
