## Task

### 🇵🇱 Treść zadania (PL)

Utwórz zapytanie wyświetlające ranking średniej ocen studentów. Ranking powinien zawierać informacje o studencie tj. Nr albumu, Imię oraz Nazwisko, Średnią ocen a także Pozycję w rankingu (1, 2, 3...). Wykorzystaj w zadaniu funkcję rank().

### 🇬🇧 Task description (EN)

Create a query displaying a ranking of students' grade averages. The ranking should contain information about the student, i.e. Album number, First name and Last name, Grade average and also the Position in the ranking (1, 2, 3...). Use the rank() function.
